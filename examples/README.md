# Examples

This directory contains opinionated, concrete examples of how to run the HA–Loxone bridge in real setups.

These examples are **not** generic. They are meant as blueprints you can read, copy and adapt to your own environment.

Currently included:

- `rb5009-humidifier` – a full example of how the bridge is used in a real MikroTik RB5009 setup to integrate a Levoit 6000S humidifier with Loxone.

For the overall architecture and a more detailed description of the project, see the main [`README.md`](../README.md).
