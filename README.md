# HA–Loxone Bridge

Náš bridge mezi Loxone a Home Assistantem zabalený jako Docker image, dostupný pro více platforem (amd64, arm64, arm).

## Jak to použít

> Tuhle sekci doplníme, až budeme mít první release image a “kanonický” příkaz `docker run`.

## Jak to funguje

Bridge běží v Docker kontejneru a zprostředkovává komunikaci mezi Loxone a Home Assistantem.

## DIY: Build z kódu (pro fajnšmekry)

Tento projekt obsahuje i nástroje pro sestavení multi-arch Docker image pomocí GitHub Actions a Docker Buildx.
